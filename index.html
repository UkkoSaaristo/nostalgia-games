Каталог игр

Старые игры в одном месте.

Инструкция

ЕСЛИ НА ДВУХ ДИСКАХ

  1. Скачать архив с нужной игрой
  2. Распаковать нужную игру себе на компьютер
  3. Открыть папку с нужной игрой (например "Смерашики. Круглая компания")
  4. На первый файл (disk 1) нажимаем правой кнопкой мыши
  5. "Открыть с помощью" »»» "Проводник"
  6. Нажимаем "Setup" и выполняем установку
  7. После установки выбираем второй файл (желательно сначала извлечь первый файл через "мой компьютер")
  8. Повторяем действия из пунктов "4" и "5" со вторым файлом
  9. Включаем игру и наслаждаемся

ЕСЛИ НА ОДНОМ ДИСКЕ

  1. Скачать архив с нужной игрой
  2. Распаковать нужную игру себе на компьютер
  3. Открыть папку с нужной игрой (например "Губка Боб")
  4. На файл нажимаем правой кнопкой мыши
  5. "Открыть с помощью" »»» "Проводник"
  6. Нажимаем "Setup" и выполняем установку
  7. Включаем игру и наслаждаемся

Если архив защищён паролем, укажите здесь, где его найти.

Видеоинструкция

Каталог игр · файлы находятся на внешних облачных дисках
